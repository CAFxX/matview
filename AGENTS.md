The implementation must be of the highest quality, reliability, and maintainability.

Each feature smust be fully generic and fully generically tested,
both in isolation as well as with any possible combination of other features,
both in its default configuration and any possible configuration,
against all possible inputs both expected as well as adversarial.
Tests must be both hand-crafted as well as randomized and property-based.
A feature must not be considered "done" until all of the above is true and
has been verified independently by a reviewer.

Technical debt (e.g. leftover cruft, missing or flaky tests, etc.) must be
proactively dealt with. If any technical debt is identified it must be addressed
in standalone commits even if outside of the scope of the current work.
